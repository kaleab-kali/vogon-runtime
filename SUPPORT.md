# Support

Vogon Runtime is pre-release open-source software. The best support channel
depends on the kind of request.

## Questions

Open a GitHub discussion or issue if you need help understanding workflow
execution, replay verification, provider configuration, or release artifacts.
Include the Vogon Runtime version, the command you ran, and the relevant
workflow or replay fixture when possible.

## Bugs

Use the bug report issue form for reproducible problems. Include:

- `vogon --version`, a release tag, or a Git commit SHA.
- The operating system and Rust version.
- The exact command that failed.
- A minimal workflow or replay file that reproduces the problem.

Remove API keys, private prompts, credentials, and sensitive replay data before
posting.

## Feature Requests

Use the feature request issue form for runtime, CLI, provider adapter, replay,
documentation, or release process improvements. Describe the workflow problem
first, then the interface or behavior you want.

## Security

Do not open public issues for vulnerabilities. Use GitHub Security Advisories:

https://github.com/kaleab-kali/vogon-runtime/security/advisories/new

See `SECURITY.md` for the security policy.
