# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Expected Behavior

- Be respectful and direct.
- Focus technical feedback on the work.
- Make room for maintainers and contributors with different experience levels.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private information without explicit permission.
- Repeated disruption of project discussions.

Maintainers may remove comments, close issues, or block contributors who violate
these expectations.
